# NEXUS LAB — Inicio 0.1

Este paquete contiene el primer prototipo web de NEXUS LAB.

## Qué hace
- Presenta los módulos iniciales.
- Permite introducir una pregunta de investigación.
- Genera localmente una estructura de cinco pasos para planificarla.

## Qué NO hace todavía
- No llama a un modelo de IA.
- No busca artículos en internet.
- No ejecuta experimentos científicos.
- No guarda investigaciones en una base de datos.

## Cómo probarlo desde Android
1. Descomprime el ZIP en un entorno de desarrollo web en la nube o en un editor que permita servir archivos HTML.
2. Abre `index.html` en la vista previa.
3. Escribe una pregunta y pulsa “Crear plan de investigación”.

## Siguiente etapa

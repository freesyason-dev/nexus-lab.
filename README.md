# NEXUS LAB 0.4 — REASONING

## Qué incluye
- RESEARCH: búsqueda bibliográfica en Crossref.
- REASONING: análisis heurístico de resúmenes o fragmentos; clasifica señales teóricas/experimentales/observacionales, detecta frases de método, resultados, métricas y limitaciones, y propone preguntas abiertas.
- CORE: experimento Collatz en el navegador con BigInt y verificación independiente del máximo recorrido.
- Exportación de informe TXT.

## Instalación en GitHub Pages
1. Descarga y extrae `NEXUS_LAB_v0_4.zip`.
2. Abre la carpeta `nexus_lab_v0_4`.
3. Sube el archivo `index.html` a la raíz del repositorio `nexus-lab`, reemplazando el anterior.
4. Confirma con **Commit changes**.
5. Espera unos minutos y abre https://freesyason-dev.github.io/nexus-lab/

## Límites científicos
REASONING usa reglas heurísticas y coincidencia de palabras/frases. No es un modelo de IA, no comprueba si una afirmación es verdadera, no lee artículos completos automáticamente y no sustituye revisión humana. La clasificación puede fallar si el texto está en otro idioma o usa vocabulario distinto. Crossref ofrece metadatos y solo algunos registros incluyen resumen.

No coloques claves privadas ni contraseñas en `index.html` o en un repositorio público.

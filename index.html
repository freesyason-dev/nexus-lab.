Motor de análisis estructurado

Pega un resumen, fragmento o conjunto de resultados. El motor identifica señales lingüísticas y organiza preguntas; no sustituye una revisión científica.

Marco de evaluación

1. Tipo de afirmación

Teórica, experimental, observacional o descriptiva.

2. Señales de evidencia

Método, muestra, datos, comparación y resultados.

3. Límites

Restricciones, incertidumbre y aspectos no demostrados.

4. Próxima prueba

Preguntas concretas que podrían investigarse.

Experimento Collatz

Examina una cantidad finita de enteros positivos y registra cuántos pasos tardan en llegar a 1.

Regla examinada

Si n es par, n → n/2. Si n es impar, n → 3n + 1. Se repite hasta llegar a 1 o alcanzar el límite.

Probar muchos casos no demuestra la conjetura para todos los enteros positivos. Este módulo produce evidencia experimental finita.
